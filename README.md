# Hugging Face Text Classification

A machine learning project implementing text classification using state-of-the-art transformer models from the Hugging Face ecosystem.

## 🔗 Quick Links
* **Model on Hugging Face:** [prathameshkate15/food_not_food_text_classifier-distilbert-base-uncased](https://huggingface.co/prathameshkate15/food_not_food_text_classifier-distilbert-base-uncased)
* **Live Demo (Hugging Face Space):** [Food Or Not Food Classifier Space](https://huggingface.co/spaces/prathameshkate15/Food_Or_Not_Food_Classifier)

## 🚀 Features
* Data preprocessing and tokenization using `datasets` and `transformers`.
* Fine-tuning pre-trained language models (e.g., DistilBERT).
* Model evaluation and performance metrics (Accuracy, F1-Score, Precision, Recall).
* Real-time inference pipeline for custom text inputs.

## 🛠️ Tech Stack
* Python 3.x
* PyTorch
* Hugging Face Transformers & Datasets
* Gradio / Streamlit
* Scikit-learn / Pandas
